# setlog

Web版 Setlog — 親しい友人との「同じ1日、それぞれの瞬間」を共有する SNS アプリのプロトタイプ。

## コンセプト

韓国発の SNS「Setlog」を参考にしています：

- プライベートな「ログルーム」で友人と日常を共有
- 画像付きの Log 投稿、即時の Zip（気軽な写真・テキスト）
- リアクションとコメント
- 日別の Log をまとめた「vlog」風 daily summary
- ルームコードで参加、ルームロックでメンバー制限

## 機能

- プロフィール設定（名前とカラー）
- ログルーム作成（2〜5人 / 5〜20人相当）
- コードでルーム参加
- Log 投稿：画像 URL + キャプション + 横向き/縦向き
- Zip 投稿：即興の画像/テキスト
- 絵文字リアクション、コメント
- クラシック/新レイアウト切り替え
- ルームロック
- localStorage によるデータ永続化

## 技術スタック

- Vite
- React 19
- TypeScript
- Tailwind CSS 4
- lucide-react

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 注意

- このプロトタイプではカメラ機能の代わりに画像 URL 入力を使用しています。
- すべてのデータはブラウザの localStorage に保存されます。
